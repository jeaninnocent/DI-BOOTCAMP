Identification des types de données (Structuré vs Non structuré)
Les rapports financiers d’une entreprise stockés dans un fichier Excel : Structurées (Organisées en lignes et colonnes claires).

Photographies téléchargées sur une plateforme de réseaux sociaux : Non structurées (Données de pixels, sans format tabulaire inhérent).

Une collection d’articles d’actualité sur un site web : Non structurées (Texte libre, blocs de mots).

Données d’inventaire dans une base de données relationnelle : Structurées (Stockées dans des tables SQL avec des schémas définis).

Interviews enregistrées issues d’une étude de marché : Non structurées (Fichiers audio).
