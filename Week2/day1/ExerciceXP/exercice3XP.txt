Exercice 3 : Identification des types de données
En nous basant sur les structures classiques des jeux de données de l'Exercice 2 :

Jeu de données sur le sommeil :

Age : Quantitative (Nombre mesurable représentant les années vécues).

Gender (Genre) : Qualitative (Catégorie descriptive).

Hours_of_Sleep : Quantitative (Valeur numérique mesurable).

Jeu de données sur la santé mentale :

Country (Pays) : Qualitative (Nom géographique, nominal).

Year (Année) : Quantitative ou temporelle (Mesure du temps).

Prevalence_Rate (%) : Quantitative (Pourcentage continu mesurable).

Jeu de données sur les cartes de crédit :

Annual_Income (Revenu annuel) : Quantitative (Valeur monétaire).

Approval_Status (Approuvé/Refusé) : Qualitative (Catégorie binaire/nominale).
